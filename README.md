# 六层楼先生视角 Skill（liu-ceng-lou-perspective）

一个基于**六层楼先生**（前妇产科医生、女性健康科普创作者）公开作品构建的人物思维 Skill，供支持 Agent Skill 机制的助手（如 OpenCode、Claude Code）以项目级方式安装使用。

它提炼的是六层楼先生的**思维框架与表达方式**：当你想「用六层楼的视角」分析女性健康科普、身体羞耻、医患沟通、健康谣言、全面性教育与知情选择等话题时，让 Agent 以他的框架来拆解问题。

> 这是基于公开资料的框架重建，**不是本人观点，也不替代医生面诊**。

## 核心内容

根目录的 [`SKILL.md`](SKILL.md) 包含：

- **6 个心智模型**：去上游看看 · 动态基线 · 利益—羞耻—名字审计 · 双向风险与监护门槛 · 证据与反身纠错 · 处境中的知情选择
- **9 条决策启发式**：如「重复问题先上移一层」「吓人名字先做审计」「观察必须带安全绳」「受众越大，答案越谨慎」等
- **表达 DNA**：口语短句、先给方向再讲机制、生活化类比、确定性与安全边界的分寸
- **医学安全与诚实边界**：急性危险信号优先升级、原书医学内容只用于理解思维、框架推断与本人原话可分辨

## 获取仓库

```bash
git clone https://github.com/jasonisbrave/liu-ceng-lou-perspective-skill.git
```

## 项目级安装

把 `SKILL.md` 复制到你项目的 Skill 目录下（目录名即 Skill 名）：

```bash
mkdir -p .claude/skills/liu-ceng-lou-perspective
cp liu-ceng-lou-perspective-skill/SKILL.md .claude/skills/liu-ceng-lou-perspective/SKILL.md
```

安装后，在对话中使用触发语即可激活，例如「用六层楼的视角」「六层楼会怎么看」「老六模式」「切换到六层楼」。一般性健康或医疗问题**不会**自动触发本 Skill。

## 调研与验证方法

- **方法**：女娲人物蒸馏 + 仓颉拆书；本地语料优先（3 本原书全文精读），网络资料补充（访谈、播客、演讲、报道）。
- **来源管理**：逐条来源复核见 `references/research/source-verification.md`；矛盾证据保留并标注；不采用知乎、微信公众号、百度百科等内容作为依据。
- **验证**：构建期自动质量检查 6/6 通过；独立测试已知测试 3/3、边缘场景与风格测试通过；阶段记录见 `validation/`。

## 医学安全边界

- 本 Skill 是**科普思维框架**，不构成诊疗建议，不替代医生面诊，不具备任何诊断或治疗能力。
- 对话中出现急性危险信号（剧烈疼痛、大量出血、意识异常等）时，Skill 会优先建议立即联系急救或前往急诊。
- 原书出版于 2019–2024 年，其中的剂量、流程、政策等信息**不得**当作现行医学建议，使用时必须现查权威来源。
- Skill 不会因一般性健康或医疗问题自动触发，除非用户明确要求六层楼视角。
