# 降级与审计说明

本目录保存未通过三重验证的框架候选。`f13.md`、`f18.md`、`f19.md`、`f20.md` 为 4 条独立降级记录；其余 18 条框架已作为组件并入 7 个通过单元，映射见 `../verified.md`。

原则（p01–p66）主要作为作者行动规则与历史医学语境证据；案例（c/cf）用于 A1 支撑；反例（ce）用于 B 边界；术语（g）用于统一定义。它们不因为未单独验证而被视为“无价值”，也不应全部硬凑成独立心智模型。

含 `audit` 或 `time-sensitive-evidence` 标记的医学内容，只能作为 2019 年原书历史材料，不能直接作为 2026 年诊疗建议。
